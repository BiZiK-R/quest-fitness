# Intake extract — customer Telegram (2026-09-29)

Source: Artem (заказчик / Quest с пробкой) ↔ Andrey (исполнитель)

## Product intent
- Перенести функционал близкий к https://ocoach.ru/, но:
  - **Убрать:** расчёт ЗП / выручки (считается в другом месте)
  - **Убрать:** запись клиентов (календарь записи/бронирования)
- Mobile-first («больше в мобилку»)
- Дизайн: минимализм, понятный UI, чёткие последовательные шаги; референс ребрендинга — направление с драконом
- Ожидание: рабочий скелет + дальнейшая доработка фич со временем

## Roles
- **Admin:** Артем (+ права админа на вырост)
- **Trainer:** любой тренер; функционал тренера; «на вырост» почти как админ
- Achievements: добавляет только администратор

## Client cabinet tabs
1. **Тренировки:** кол-во тренировок в текущем месяце; стрик тренировок; стрик питания; календарь ближайших; какая тренировка запланирована
2. **Аналитика/статистика:** посещённые/пропущенные за месяц/3 мес/год; поднятые кг; прогресс по выбранным упражнениям во времени; нагрузка на мышцу (подходы/нед); основные мышцы 1:1, второстепенные 2:1
3. **Питание:** заданное КБЖУ; недельный график соблюдения; ввод факт КБЖУ по дням; стрик учёта питания
4. **Замеры:** вес, обхваты (руки, талия, бёдра, ягодицы, грудь) + кастомные; динамика
5. **Ачивки:** админ добавляет; клиент видит получено / не открыто; стрики; ранг
6. **Абонемент:** кол-во занятий + дата окончания

## Trainer extras
- Шаблоны тренировки: название, тип, описание, упражнения, длительность, продолжительность в микроциклах
- Шаблон макроцикла: объединение шаблонов тренировки в повторяющийся цикл с периодичностью
- База упражнений зала + кастом; primary/secondary мышечные группы (1:1 / 2:1 в статистике)

## Live workout session
- Старт заданной тренировки → таймер → упражнение за упражнением
- Подход: вес, повторения, RPE; затем следующий подход
- После упражнения — таймер отдыха
- Суперсеты: без отдыха между упражнениями суперсета; после подхода A → подход B
- Кастомные модификаторы подходов (дропсет, mio reps…) — меняют цвет
- После тренировки: статистика (подходы, тоннаж, рост % vs прошлый раз)

## Schedule / attendance semantics
- Тренировка ставится в расписание в статусе «ожидание» (вносит тренер/админ)
- В дату/время: **Начать** → live script; **Пропустить** → считается пропуском; **Отменить** → не учитывается вовсе

## Design
- PPTX: Quest-Fitness-Rebranding.pptx (сырой ребрендинг)
- Выбран вариант с драконом = направление **«Гильдия»** (слайды 6–7 в файле; палитра уголь/крем/красный/абрикос, Rubik)
- UI: минималистичный, без лишнего, понятные шаги

## Explicit non-goals (from customer)
- Payroll / revenue analytics
- Client appointment booking calendar (не путать с расписанием назначенных тренировок)
