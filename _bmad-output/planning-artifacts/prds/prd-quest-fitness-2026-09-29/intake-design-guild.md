# Design intake — Quest Fitness Rebranding (Гильдия / дракон)

Source: `Quest-Fitness-Rebranding.pptx` (сент 2026), media copied to `docs/design-refs/`

## Chosen direction (customer): «Гильдия» — dragon + kettlebell
- Logo concept: гиря с драконом в просвете; маскот для мерча; паттерн из символов
- Typography: **Rubik Bold** (заголовки), **Rubik Regular** (текст)
- Tone: дружелюбный; реальные люди; спокойный свет
- Palette:
  - Уголь `#241C20`
  - Крем `#F6EBDD`
  - Красный `#C33F46`
  - Абрикос `#EFB68C`
- Note from deck: упростить зубцы дракона; проверить узнаваемость 24–32 px
- Deck recommendation also picks «Гильдия» as first direction to develop

## Other directions (not selected, context only)
- Портал: Q-as-plate, Unbounded+Rubik, `#29132D` / `#FFF5EC` / `#EF4438` / `#FFD9C1`
- Бросок на силу: dice+bar, Noto Serif+Rubik, `#211421` / `#F5E9D8` / `#961D32` / `#DEA18F`

## Brand principles (apply to product UI later via bmad-ux)
1. Фитнес считывается сразу
2. Игра объясняется действием (не абстрактным порталом)
3. Один главный знак; маскот — второй слой
4. Цвет имеет роль: тёмный текст, светлый воздух, красный акцент
5. UX product ask from customer: минимализм, нет лишних элементов, понятные последовательные шаги

## Product UI implication for PRD (not UX spec yet)
- Mobile-first web app screens should inherit Гильдия palette + Rubik
- Avoid “AI slop” purple gradients; stay warm cream + charcoal + red accent
- Keep RPG/quest flavor secondary to clear training flows
